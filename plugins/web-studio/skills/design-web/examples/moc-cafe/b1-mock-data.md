# W1 mock data: types + realistic Vietnamese café data

## Goal
Create all typed mock data for the Mộc Café UI (landing + admin). Pages built later import ONLY from here, so names
and shapes must match this brief exactly. Content in Vietnamese, prices in VND (integers), realistic for a specialty
café in Phú Nhuận, TP.HCM. Reference "today" = 2026-10-28 (Thứ Ba). Read `design/design-brief.md` for context.

## Scope
Create only `src/lib/types.ts` and `src/lib/mock/*.ts`. Do NOT touch anything else (another job edits globals.css,
layout.tsx, src/components/motion, src/lib/format.ts right now).

## Rules
- Deterministic data: literal values or generated by pure loops with fixed seeds - no `Math.random()`, no `Date.now()`,
  no `new Date()` without an explicit ISO string. ISO strings with `+07:00` offset.
- Export `as const`-free typed arrays: `export const menuItems: MenuItem[] = [...]`.
- Images: only these paths exist: `/images/drink-ca-phe-sua-da.webp`, `/images/drink-latte-da.webp`,
  `/images/drink-cold-brew.webp`, `/images/drink-americano-da.webp`, `/images/drink-latte-nong.webp`,
  `/images/drink-cappuccino.webp`, `/images/drink-flat-white.webp`, `/images/food-croissant.webp`,
  `/images/food-croissant-dau.webp`, `/images/food-banh-ngot.webp` (reuse them across items; tea items may reuse
  latte/cold brew photos).

## Files and exports
- `menu.ts`: `categories` (3: Cà phê, Trà & khác, Bánh), `menuItems` (18: e.g. Cà phê sữa đá, Bạc xỉu, Cà phê muối,
  Americano đá, Cold brew cam sả, Latte, Cappuccino, Flat white, Espresso tonic, Matcha latte, Trà đào cam sả,
  Trà vải hoa hồng, Cacao đá xay, Croissant bơ, Croissant dâu hạnh nhân, Bánh chuối nướng, Tiramisu, Bánh bông lan trứng muối).
  Prices 29.000-79.000 ₫; size deltas S 0 / M +6.000 / L +12.000 for drinks, bakery items only size "M" delta 0.
- `orders.ts`: `orders` (40 orders on 2026-10-27 and 2026-10-28, codes "#MC2401".."#MC2440", mixed statuses with the
  newest ones in cho-xac-nhan/dang-pha/san-sang, totals consistent with items and discount).
- `tables.ts`: `areas: Area[]`, `tables` (16: Tầng trệt T01-T08, Sân vườn S01-S05, Tầng 2 L01-L03). x/y/w/h are
  percentages (0-100) inside the area's floor plan with no overlaps; mixed shapes and statuses; occupied tables point
  to an order id that exists; reserved tables have `reservedFor` like "Chị Hà · 19:30".
- `inventory.ts`: `ingredients` (20, a few below minStock), `stockMovements` (14 recent).
- `staff.ts`: `staff` (10), `currentUser` (Nguyễn Minh Anh, quan-ly).
- `shifts.ts`: `shifts` for the week 2026-10-26 .. 2026-11-01 (morning 06:30-14:30, evening 14:00-22:30), 2-4 staff per shift.
- `customers.ts`: `customers` (24, all four tiers, Vietnamese names, phones "09xx xxx xxx").
- `promotions.ts`: `promotions` (8, all three statuses).
- `reports.ts`: `dailyRevenue` (30 days ending 2026-10-28, weekend peaks, 6-14 triệu/day), `hourlySales` (hours 7..22 for
  today), `topItems` (top 8), `channelShare` (4 channels, values sum 100), `kpis`:
  `{ revenueToday, revenueDelta, ordersToday, ordersDelta, avgTicket, avgTicketDelta, newCustomers, newCustomersDelta }`
  (deltas are percent numbers vs yesterday, e.g. 12.4 or -3.1).
- `landing.ts`: `reviews` (6), `storyStats` (`[{ value: 2018, label: "Năm mở cửa" }, { value: 12, label: "Loại hạt tuyển chọn" }, { value: 4.9, label: "Đánh giá trung bình", suffix: "★" }]`).
- `notifications.ts`: `notifications` (6, mixed types, 3 unread).
- `index.ts`: re-export everything from all files.
